## Como interpretar os registros

- **Implementado:** existe código/regra implantada no staging.
- **Validado tecnicamente:** passou pelas verificações registradas daquela entrega; não significa que todas as integrações externas foram testadas.
- **Aceito no uso:** houve confirmação do usuário para aquele comportamento. Não presumir aceite geral a partir de “continue”.
- **Planejado:** escopo futuro, não entrega concluída.
- **Histórico:** descreve o momento da medição; contagens, bundles e pendências antigas podem ter sido superados.

O código e o banco atuais confirmam o comportamento. Para interpretar intenção e pendências, use esta consolidação. Um documento antigo não deve prevalecer só porque seu título diz “completo”. A numeração de **sete fases do programa mestre** é a adotada aqui; o plano preliminar de cinco fases e as fases internas do módulo de tráfego são outros roteiros.

## Portabilidade e manutenção

Esta pasta usa Markdown e JSON, com links relativos, e pode ser copiada para a pasta `docs/continuidade-planeje` do código. O pacote inclui referências históricas selecionadas e manifests de entrega; não inclui banco, segredos ou uma cópia completa do aplicativo.

Para ler ou enviar o contexto num único arquivo, use [PLANEJE-CONTEXTO-COMPLETO.md](PLANEJE-CONTEXTO-COMPLETO.md). O ZIP portátil também inclui os arquivos de entrada dos agentes. Para regenerar arquivo combinado/ZIP depois de atualizar os documentos: `python3 docs/continuidade-planeje/ferramentas/recriar_pacote.py` a partir da raiz; `--output-dir` permite escolher outra pasta de saída.

Os arquivos `AGENTS.md`, `CLAUDE.md` e `.cursor/rules/planeje-contexto.mdc` na raiz ajudam ferramentas a localizar o contexto. Ferramentas que não carregam esses arquivos automaticamente devem receber o documento 08 ou esta pasta explicitamente.

Depois de cada mudança, atualize **01, 02, 03 quando houver decisão nova, 06 e 07**, além do manifesto de release. Use data, ambiente, teste realizado, limitações e caminho do backup. Não escreva credenciais nos documentos.
