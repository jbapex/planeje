## Modelo de dados (Entrega A)

### `caixa_dot_threads`

- `owner_id` → `profiles.id` (dono do tópico)
- `kind`: `demanda` \| `conversa` \| `aviso`
- `origin`: `mcp` \| `usuario` \| `evento`
- `title`, `status` (`aberta` \| `aguardando_dot` \| `respondido` \| `feita` \| `arquivada`)
- `priority`: `baixa` \| `normal` \| `alta`
- `cliente_id`, `task_id`, `href` opcionais
- `created_by_kind`: `usuario` \| `mcp` \| `sistema`
- `created_by_id`, `created_by_label`
- `last_message_at`, `last_message_preview`, `unread_for_owner`

### `caixa_dot_messages`

- `thread_id`, `role` (`user` \| `dot` \| `system`), `body`, `meta` jsonb, `created_by_id`, `created_at`

### RLS

- Colaborador: só `owner_id = auth.uid()`
- Admin / super admin: lê todos (painel Equipe)
- MCP usa service role (bypass)

SQL: `20261005120000_caixa_dot.sql` — aplicar uma vez. Não reaplicar.

## MCP (Entrega A)

### `criar_demanda_caixa`

| Campo | Obrigatório | Notas |
| --- | --- | --- |
| `titulo` | sim | Título do tópico |
| `corpo` | sim | Primeira mensagem `system` |
| `profile_id` | um de | UUID do destinatário |
| `nome` | um de | Match em `profiles.full_name` (ilike) |
| `prioridade` | não | `baixa` \| `normal` \| `alta` (padrão `normal`) |
| `cliente_id` | não | UUID |
| `task_id` | não | UUID |
| `href` | não | Rota interna, ex. `#/tasks/...` |

Cria thread `kind=demanda`, `origin=mcp`, mensagem `system` com o corpo. Não envia WhatsApp. Não chama IA.

### `listar_demandas_caixa`

- Admin / super admin / admin_key: lista da equipe (filtro opcional `profile_id`, `status`, `limite`)
- Colaborador: só as próprias

Versão MCP alvo desta leva: **2.7.0**. Reconectar o ChatGPT após restart do processo.

**ChatGPT / OAuth (06/10/2026):** o cliente só habilita ~55 tools. Em sessão OAuth o servidor aplica `chatgptToolBudget` (núcleo com `criar_demanda_caixa` e `listar_demandas_caixa` sempre enabled). Token pessoal / Cursor continua com a lista completa. Quem responde no app é a edge `caixa-dot-ia`, não o MCP.
